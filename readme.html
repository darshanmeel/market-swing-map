Market swing map

One offline page for every market: how far it is below its all-time high, its real turning points, and what every past fall this deep did next. Each weekday after the close a new guess, a year ahead, is saved and scored against what really happens.

It covers about 540 markets, listed in markets.csv and grouped in the Index, stock or commodity list at the top of the page:

  • Indices: Nasdaq Composite, Nasdaq-100, S&P 500, Dow Jones, Dow Transports, Russell 2000, NYSE Composite, DAX 40, FTSE 100, CAC 40, Euro Stoxx 50, Stoxx Europe 600, Nikkei 225, KOSPI, Hang Seng, Shanghai Composite, Sensex, Nifty 50, S&P/TSX and ASX 200.
  • Commodities and crypto: gold, silver, WTI crude oil and Bitcoin.
  • Companies: the Nasdaq-100 and the 30 Dow stocks.
  • S&P 500: the S&P 500 members not already under Companies.

Every tile, chart and table has an i button that explains it in plain words.

Not investment advice and not a forecast. The pages show what happened after similar falls in the past; the next fall can behave unlike any of them.

Quick start

pip install yfinance pandas plotly
python market_highs.py              # every market in markets.csv, one process per CPU core
python market_highs.py "^IXIC" "^GSPC"  # only these (Yahoo symbols)

Run it from this folder. Quote symbols that start with ^: in Windows cmd an unquoted ^ is dropped. A market that fails is printed with its error and the run ends with a non-zero exit code; the others are still built. A run for only some markets updates their rows in market_highs.csv and keeps the others.

Then open index.html in a browser for every market at a glance, or app.html (the Nasdaq Composite), or pick a market with ?m=: app.html?m=gspc. highs_ixic.html and the other highs_*.html still work and open the same page. It works offline; plotly.min.js is written next to it on every run. The data files are not kept in git; each machine builds its own.

The list: every market in markets.csv, as Name (SYMBOL), grouped as in the file. A built market shows its last close date; one not built yet is greyed and says not built yet. A click on a market, Enter or the Open button opens it (arrow keys only move through the list). Picking one not built yet opens a short panel with the exact command to build it and a Copy button. The list comes from data/index.js, which every run rewrites, so it is current for every market, also after a run for only a few. In a folder with nothing built yet, the page shows python market_highs.py to build them all.

Build from the page: python market_highs.py --serve (or --serve 8080; default port 8765) serves this folder on http://127.0.0.1:8765/app.html (or localhost), reachable only from this computer. Opened from there, a market not built yet gets a Build now button and a built one a small Rebuild link; the page reloads when the build is done. One build runs at a time, for at most 30 minutes, and only for markets in markets.csv. Opened from disk, the page shows the command and the Copy button only. Ctrl+C stops the server.

Add a company or index: python market_highs.py --add "SPOT" "Spotify" adds the Yahoo symbol and name to markets.csv (group Companies; --group "Indices" for an index) and builds it. A symbol Yahoo has no data for is not added. Only the new market's history is downloaded; the 23:00 run includes it from then on, and it is in the list straight away.

The home page

index.html is the way in: every market on one page, so I can see which of the 540 are worth a closer look. It is a starting list, not advice; the market's own page has the detail. Each row and each dot opens it.

  • Headline counts: how many markets are in an uptrend or a downtrend at both reversal sizes, at or near their record, in a fall of 20% or more.
  • Trend by group: up, mixed and down per group. Indices are read at 8% reversals, commodities and crypto at 10%, companies at 10% and at 15%. The size matters: on 20 Nov 2026 Hershey read Downtrend at 10% (its last low, 30 Sep 2026, was below the one before) and Uptrend at 15% (the fall from the 27 Feb 2026 high has not turned by 15% yet, so the last confirmed high and low are still higher ones). Both are right at their scale; the table gives the size with every label and the current move under it.
  • Scatter: distance below the record against the 5-year return per year, coloured and shaped by trend.
  • Screens: uptrend at both sizes, near the record (within 5%), a deep fall (20%+) where most past falls this deep were higher a year later, downtrend at both sizes.
  • The list: every market, filtered by group, searched by name or ticker and sorted by any column: trend, distance and days from the record, last close and day move, returns over 1, 5 and 10 years (5 and 10 per year), the deepest fall below the record in 5 and 10 years, 1-year volatility, how many past 10%+ falls went deeper than today, and how many past falls this deep were higher a year later. The mark before the name is the same freshness mark as in the market list.
  • Indices: each index at 8% with its 5- and 10-year return and deepest fall.

The numbers are worked out in Python with the same rules as the market page and saved in data/index.js, so the home page never loads the large market files. Every build refreshes them for the markets it builds; the others keep theirs. python market_highs.py --summary-only works them out again for every market from the closes already in data/closes.csv, without downloading or building pages: about a minute for all of them.

How it works

The script writes each market's numbers to data/<market>.js. app.html is one page for every market: it reads ?m=<market> (default ixic), loads that file and draws the charts, so building only some markets leaves the others as they were. All the history maths runs in Python once per run; the page only redraws charts when a setting changes. All-time highs use the full history Yahoo has for each market, so a high is a real record, not just the top of the shown window.

Daily guesses

Each run saves one guess per market for that day's close in predictions/<market>.json. A rerun on the same day replaces that day's guess; older days are never changed.

How a guess is made

Each guess is made five ways from the same close, using only the data up to that day. Pick one with the Method buttons, or All methods to compare the middle paths.

MethodWhat it replays
Past deeper fallsThe 8 past falls from a record that got at least as deep, at the most similar speed, each from the day it first got there. This guess is saved in predictions/.
Shallower falls that turnedPast falls that stopped between half the current depth and the current depth, replayed from their low, as if the guess day were the bottom (needs 3 or more).
Random walkThe daily moves of this market drawn at random, 1000 paths (seeded, so a rebuild gives the same result).
Any yearEvery 1-year stretch in the history, from any starting day: what a normal year looks like.
Trend continuesThe pace of the last 60 trading days kept up for a year.

Bands hold the middle 80% of paths. The four extra methods are worked out again on every run for the guesses shown, so the files in predictions/ stay small.

How it is scored

The chart shows one guess day at a time (pick it from the list), zoomed to 1 week, 1 month, 6 months or 1 year, with the real closes printed on the black line. After every close, each saved guess gets the real close added. A guess is inside while the real close sits between its lowest and highest scenario for that day, below or above when it leaves them, the sign that this fall is unlike the past ones.

  • Bold line: the past fall the real path has followed most closely so far; the others are faded.
  • Dot colour on the real path: the past fall closest to that day's close.
  • Method table under the chart: each method's average miss against the real closes so far; the smallest is bold.
  • Summary bullets under the chart: the move since the guess, the fall it follows, inside or outside the scenarios, and the closest fall each day.

On a market's first run, the last 20 trading days' guesses are made from the data each day had, so scoring starts at once.

Running it every day

On Windows a scheduled task runs the script Monday to Friday at 23:00 (after the US close at 22:00 Central European time) and appends the output to predictions/run.log:

$a = New-ScheduledTaskAction -Execute "cmd.exe" -WorkingDirectory "<repo folder>" `
     -Argument '/c "python -P -E market_highs.py >> predictions\run.log 2>&1"'
$t = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Monday,Tuesday,Wednesday,Thursday,Friday -At 23:00
$s = New-ScheduledTaskSettingsSet -StartWhenAvailable -RunOnlyIfNetworkAvailable -ExecutionTimeLimit (New-TimeSpan -Hours 2)
Register-ScheduledTask -TaskName "Swing map daily" -Action $a -Trigger $t -Settings $s

The task runs while the user is logged on; if the computer is off at 23:00 it runs at the next start.

Limits

  • Small samples: most markets have 5 to 20 past falls this deep, each with its own cause.
  • Gold, silver and oil use Yahoo's front-month futures, which start in 2000; their "all-time high" is the highest since then. WTI's negative closes of April 2020 are dropped, since % moves and a log scale need positive prices.
  • A run during market hours uses the live price as the last close; the evening run replaces it.
