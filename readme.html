    How Below the Record works

    One offline page for every market: how far it is below its all-time high, its real turning points, and what every past fall this deep did next. Each weekday after the close a new guess, a year ahead, is saved and scored against what really happens.

    Every tile, chart and table has an i button that explains it in plain words.

    Not investment advice and not a forecast. The pages show what happened after similar falls in the past; the next fall can behave unlike any of them.

    Quick start

    Install the three packages, then build every market (one process per CPU core) or just the ones you name by Yahoo symbol. Run it from this folder.

    Terminal
    pip install yfinance pandas plotly
python market_highs.py                    # every market in markets.csv
python market_highs.py "^IXIC" "^GSPC"    # only these

    A market that fails is printed with its error and the run ends with a non-zero exit code; the others are still built.

    Open the pages

    Open index.html for every market, app.html for the Nasdaq Composite, or app.html?m=gspc for one. Works offline; plotly.min.js is written next to it on every run.

    The data files are not kept in git; each machine builds its own.

    Build from the page

    python market_highs.py --serve (or --serve 8080; default port 8765) serves this folder on http://127.0.0.1:8765/app.html, reachable only from this computer.

    From there a market not built yet gets a Build now button and a built one a Rebuild link; the page reloads when done. One build at a time, at most 30 minutes, only markets in markets.csv. Ctrl+C stops the server. Opened from disk, the page shows the command and a Copy button only.

    Add a market

    python market_highs.py --add "SPOT" "Spotify" adds the Yahoo symbol and name to markets.csv and builds it. Group Other US-listed by default; --group "S&P 500" for a member, --group "Indices" for an index.

    A symbol Yahoo has no data for is not added. Only the new market’s history is downloaded; it is in the list straight away and in the 23:00 run from then on.

    Windows tip

    Quote symbols that start with ^: in cmd an unquoted ^ is dropped.

    The market list on each page

    Every market in markets.csv, as Name (SYMBOL), grouped as in the file. A built market shows its last close date; one not built yet is greyed and says not built yet. A click, Enter or the Open button opens it (arrow keys only move through the list). Picking one not built yet opens a short panel with the exact command to build it and a Copy button. The list comes from data/index.js, which every run rewrites, so it is current for every market, also after a run for only a few. In a folder with nothing built yet, the page shows python market_highs.py to build them all.

    The home page

    index.html is the way in: every market on one page, so you can see which are worth a closer look. A starting list, not advice; each row and each dot opens the market.

    Headline and breadth
    How many markets sit in each band below their record, and how many are up- or down-trending at every reversal size their group is read at.
    Screens
    Uptrend at every size, near the record (within 5%), deep falls (20%+) where most past falls this deep were higher a year later (at least 3 past falls), downtrend at every size.

    An uptrend whose last close is already below its last swing low is left out of the uptrend screen and count, and a downtrend above its last high out of the downtrend ones: the turn is under way, just not confirmed yet. The list says so (below last low, above last high).

    Worth a closer look
    Markets unusual for themselves: far below or near the record, near their 10-year worst, a fresh turn, or a big day, each against its own normal swing.
    Trend by group
    Up, mixed and down per group, at the size that suits it: indices and futures 8%, commodities and crypto 15%, companies and ETFs 10%, with 15% one click away.

    The size matters: on 20 Nov 2026 Hershey read Downtrend at 10% (its last low, 30 Sep 2026, was below the one before) and Uptrend at 15% (the fall from the 27 Feb 2026 high had not turned by 15% yet). Both are right at their scale; the list gives the size with every label.

    Scatter
    Distance below the record against 5-year return per year, coloured and shaped by trend.
    Indices
    Each index at 8% reversals with its 5- and 10-year return per year and its deepest fall in 5 and 10 years.
    Your watchlist
    Starred markets, kept in this browser only.
    All markets
    Filter by group, search by name or ticker, and sort: trend, distance and days from the record, last close and day move, returns over 1, 5 and 10 years (5 and 10 per year), deepest fall in 5 and 10 years (since listing for a shorter history), 1-year volatility, how many past 10%+ falls went deeper than today, and how many past falls this deep were higher a year later. The mark before the name shows how fresh the data is. Star a market to keep it on your watchlist (this browser only). A market opens at the reversal size of the first label in its row (app.html?m=hsy&r=10).

    The numbers are worked out in Python with the same rules as the market page and saved in data/summary.js, so the home page never loads the large market files. Every build refreshes them for the markets it builds; the others keep theirs. python market_highs.py --summary-only works them out again for every market from the closes already in data/closes.csv, without downloading or building pages: about a minute for all of them.

    How it works

    Yahoo Financedaily closes
    →
    market_highs.pykeeps data/closes.csv
    →
    data/<market>.js · read by app.html?m=<market>
    predictions/<market>.json · one guess a day

    The script writes each market’s numbers to data/<market>.js. app.html reads ?m=<market> (default ixic), loads that file and draws the charts, so building only some markets leaves the others as they were. All the history maths runs in Python once per run; the page only redraws charts when a setting changes. All-time highs use the full history Yahoo has, so a record is a real record, not just the top of the window shown.

    The market page

    Market page sections
    Top of the pageLast close, distance from the record (and from the 10-year high when the record is older), days since it and the speed of the fall, how past falls this deep ended, the current swing and the trend shape, and where today sits in its 5-year range.
    The swingsPrice with turning points at the reversal size you pick (3–20%), over 1 to 10 years. A high or low counts once the price reverses by that size, so daily 1–2% noise is ignored. Hover a leg for its points and length. Below: the drawdown strip, the last eight turns (HH / LH / HL / LL / ATH), a typical swing, support and resistance levels, and every swing in view as a table.
    How deepEvery fall of 10%+, from the record (a drop before the old high is regained stays part of the earlier fall) or from the last swing high (every 10% drop counts on its own), over 10 years or since 1980, with time back to the record.
    What came nextEvery earlier fall that got this deep: how many fell 5, 10 or 20% further (with the price that would mean today), the total fall, the days to get there, time back to the old high, the year after, and the rise before the next 10% fall; buttons replay each past year from today, or from 10, 20 or 30% lower.
    GuessesPast falls replayed from today’s close, five methods, pick a guess day, scored against the real closes as they come in; plus a back-test: at each past fall, what earlier falls alone suggested against what really happened.
    ReferenceHighs and lows against the last close, and the last 30 trading days.

    Daily guesses

    Each run saves one guess per market for that day’s close in predictions/<market>.json. A rerun the same day replaces it; older days never change. Each guess is made five ways from the same close, using only data up to that day:

    Past deeper falls
    The 8 past falls from a record that got at least as deep, at the most similar speed, each from the day it first got there. This one is saved to predictions/.
    Shallower falls that turned
    Falls that stopped between half and all of today’s depth, replayed from their low, as if the guess day were the bottom (needs 3+).
    Random walk
    This market’s daily moves drawn at random, 1,000 paths, seeded so a rebuild gives the same result.
    Any year
    Every 1-year stretch in the history, from any starting day: what a normal year looks like.
    Trend continues
    The pace of the last 60 trading days kept up for a year.

    Bands hold the middle 80% of paths. The four extra methods are worked out again on every run for the guesses shown, so the files in predictions/ stay small. On a market’s first run, the last 20 trading days’ guesses are made from the data each day had, so scoring starts at once.

    After every close each saved guess gets the real close added: it is inside while the real close stays between its lowest and highest path, and below or above when it leaves them, a sign this fall is unlike the past ones.

    • Methods and zoom: pick one method with the Method buttons, or All methods to compare the middle paths; pick a guess day and zoom to 1 week, 1 month, 6 months or 1 year. Bullets under the chart give the move since the guess, the fall it follows, inside or outside, and the closest fall each day.
    • Bold line: the past fall the real path has followed most closely so far; the others are faded.
    • Dot colour on the real path: the past fall closest to that day’s close.
    • Method table: each method’s average miss against the real closes so far; the smallest is bold.
    • How earlier guesses are doing: each guess day, its range today and whether the real close is inside, below or above.

    Running it every day

    On Windows, a scheduled task runs the script Monday to Friday at 23:00 (after the US close at 22:00 Central European time) and appends its output to predictions/run.log. It runs while the user is logged on; if the computer is off at 23:00 it runs at the next start.

    PowerShell
    $a = New-ScheduledTaskAction -Execute "cmd.exe" -WorkingDirectory "<repo folder>" `
     -Argument '/c "python -P -E market_highs.py >> predictions\run.log 2>&1"'
$t = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Monday,Tuesday,Wednesday,Thursday,Friday -At 23:00
$s = New-ScheduledTaskSettingsSet -StartWhenAvailable -RunOnlyIfNetworkAvailable -ExecutionTimeLimit (New-TimeSpan -Hours 2)
Register-ScheduledTask -TaskName "Below the Record daily" -Action $a -Trigger $t -Settings $s

    Limits

    • Small samples. Most markets have 5 to 20 past falls this deep, each with its own cause.
    • Futures history. Gold, silver and oil use Yahoo’s front-month futures from 2000, so their “record” is the highest since then. WTI’s negative closes of April 2020 are dropped, since % moves and a log scale need positive prices.
    • Intraday runs. A run during market hours uses the live price as the last close; the evening run replaces it.

    Files

    Files in this folder
    market_highs.pyDownloads the closes, works out highs, falls, similar cases and guesses, writes the data files.
    markets.csvEvery market: Yahoo symbol, name and group. Edit it to add or remove markets.
    index.htmlThe home page. Reads data/index.js and data/summary.js.
    app.htmlThe page for every market. Opens data/<market>.js for ?m=<market>.
    data/index.jsThe market list: symbol, group, last close and build time, rewritten every run (not in git).
    data/summary.jsHome page numbers per market, rewritten every run; markets not rebuilt keep theirs (not in git).
    data/<market>.jsOne market’s numbers for its page, rewritten when it is built (not in git).
    plotly.min.jsThe chart library, written on every run (not in git).
    predictions/One file per market with every saved daily guess.
    data/closes.csvEvery market’s daily closes, kept between runs (not in git). A run downloads only the last few days; a market’s full history again only when it is new or a split changed its old closes. Delete it to download everything again.
